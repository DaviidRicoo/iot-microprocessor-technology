# 🔌 Digital and Microprocessor Technology with IoT Elements

> **Universidad:** WSB Merito Gdańsk (Programa Erasmus+)  
> **Grado:** Ingeniería Informática de Software  
> **Tecnologías clave:** C/C++, Microcontroladores (ESP32 / Arduino), IoT, Sensores, Protocolos (MQTT, HTTP)

---

## 📌 Descripción del Repositorio

Este repositorio contiene las prácticas, laboratorios y circuitos desarrollados en la asignatura **Digital and Microprocessor Technology with IoT Elements**. El objetivo principal es comprender la arquitectura de microprocesadores, la programación de sistemas embebidos en C/C++ y la comunicación de dispositivos IoT con plataformas en la nube.

---

## 🛠️ Herramientas y Stack Tecnológico

* **Lenguajes:** C / C++
* **Hardware & Microcontroladores:** ESP32, Arduino, Raspberry Pi, Sensores y Actuadores (DHT11, LED, Servos)
* **IDEs & Software:** PlatformIO, Arduino IDE, SimulIDE / Proteus, VS Code
* **Protocolos IoT & Nube:** MQTT, HTTP/REST, Wi-Fi, ThingSpeak / Blynk
